# A mulhar da Times Square

## 📒 Descrição
Foto de uma mulher sorrindo em NY

## 🤖 Tecnologias Utilizadas
Copilot

## 🧐 Processo de Criação
Coloquei o seguinte pronpt:
"Gerar imagem totalmente realista de uma mulher de cabelos longos, corpo esguio e estatura mediana. Ela deve estar sorrindo para uma foto tirada em frente e times square em NY. Seu vestido deve ser sóbrio, porém elegante. Vestido esse na cor creme. Ela deverá estar usando uma bolsa pequena, salto alto e óculos escuros.
Ela deverá posar olhando para a foto, foto esta que deverá contemplar o corpo todo."
